# Pallhotellet.se

A modern logistics and warehouse management web platform developed for **Pallhotellet**, a Sweden-based provider of warehousing, distribution, goods handling, and 3PL services.

## Project Overview

Designed and developed a responsive, performance-focused web platform to present logistics services, streamline customer enquiries, and provide a professional digital interface for business operations.

## Core Features

* Responsive and adaptive UI
* Structured service architecture
* Customer enquiry and quotation flows
* Contact and lead-generation forms
* Customer authentication interface
* Service and content management
* Optimized navigation and user experience
* Mobile-first responsive implementation

## Technical Focus

* Component-based frontend architecture
* Responsive UI development
* Reusable interface components
* Form handling and validation
* Performance and UX optimization
* Cross-device compatibility
* Production-oriented web development
